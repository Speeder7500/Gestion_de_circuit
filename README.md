# gestion de circut

Dans le cadre de la construction d’un nouveau circuit nommé SpeedCircuit, je devais fabriquer son site web permettant tout styler de consultation jusqu’à la réservation de session ouverte au public. Une session ouverte c’est quand le circuit n’est pas réservé pour quelconque évènement et qu’il est accessible au public qui peuvent venir rouler dessus avec leur véhicule ou prendre une location parmi les véhicules qui sont mis à disposition par le personnel du circuit.
Sur le site, il y a la possibilité de se créer un compte pour pouvoir réserver une session publique par exemple ou pour consulter vos informations ou vos prochaines dates de session que vous avez réserver via ce site.
